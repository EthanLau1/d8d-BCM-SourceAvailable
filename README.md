## 🛵 项目全景与艺术主张 (Project Narrative)

### 1. 源起：垃圾场的震撼与环保执念
青年设计师 Jay 在参观大型废弃物处理场时，目睹堆积如山被随意丢弃的塑料瓶盖——那些来自每一个人日常消费的废品静静等待被填埋或焚烧。他思考：“如果这些瓶盖能被重新利用，变成帅气酷炫的机车艺术品呢？”  
随后，他遇到了拥有丰富科技管理经验的产品人 Ethan。两人一拍即合：**“把环保和电单车原创设计结合在一起，做真正有意义的文化产品。”** 团队倾力主导创作了 101 部风格迥异的原创电单车身，并首创将 109 款回收瓶盖化为机车的轮子，赋予废弃物第二重生命。

### 2. 数字升华：101 原创车架 × 回收瓶盖 = 7,700 独特藏品
团队将 101 个原创车架进行高精度数字图层解构，配以现实回收饮料罐/瓶盖元素，通过美学矩阵与平衡算法，组合出 **7,700 辆独一无二的数字机车**。

### 3. 载具与英雄：从实体工坊黏土到链上数字像素
机车是载具，HERO 属于社区。在线下实体工坊中，孩子们在桌前用彩色黏土捏出的各种生动机车骑手与环保英雄雏形，被团队进一步提炼为拥有独特环保超能力的奔跑姿态先锋，形成即将同步启动的全新 CC0 链上先锋英雄系列。

## 💻 网页展示 Demo 与核心功能 (Interactive Web Demo)

本项目在根目录下内置了一套**纯静态、免外部依赖、零框架捆绑、开箱即用**的交互式网页展示系统。

### 🚀 极简运行指引 (Quickstart)

#### 方式一：直接双击 (无需任何运行环境)
* 直接双击根目录下的 **`index.html`**，即可在任意现代浏览器中完整呈现全部版块与动画。

#### 方式二：一键启动本地轻量服务 (推荐最佳体验)
* **macOS 用户**：双击运行 **`start_demo.command`**（自动启动服务并唤起浏览器访问 `http://localhost:8888`）；
* **Windows 用户**：双击运行 **`start_demo.bat`**；
* **命令行开发者**：
  ```bash
  git clone https://github.com/EthanLau1/d8d-BCM-SourceAvailable.git
  cd d8d-BCM-SourceAvailable
  python3 -m http.server 8888
  # 浏览器访问: http://localhost:8888
  ```

### 🎨 设计与工程亮点 (Design & Engineering Highlights)

1. **Neo-Brutalism Zine 手作装帧美学**：
   - 采用 2px 墨黑实线边框（`var(--ink)`）、4px/6px 纯黑实体投影、复古纸张底衬与明黄工业强调色，呈现浓郁的机车手作车库质感。
2. **沉浸式全屏 Lightbox 模态灯箱**：
   - 工坊实录大图、进化图谱、5 位英雄立绘以及 101×120 全景合并画卷均支持点击弹窗全屏预览，支持按 `Esc` 退出与背景点击收起。
3. **原生纯前端双语系统 (i18n Engine)**：
   - 无任何 React/Vue 等框架依赖，内置原生英式英语文化语境（British English）与简体中文，支持右上角一键热切换并自动持久化存储。
4. **车库试配与海报导出引擎 (HTML5 Canvas Engine)**：
   - 基于 HTML5 离屏 Canvas，毫秒级合成底盘地面、工程原型轮组、保密车身涂装与专属概念工程水印，一键下载高保真 PNG 海报。
